# Roblox Scripts

This project provides a collection of scripts for Roblox games, including a fight button script and a part movement script. The fight button script allows players to punch, charge up to 100, and perform a grab attack. The part movement script moves a part up when a player touches it. These scripts are designed to enhance gameplay and provide interactive elements in Roblox experiences.

## Install

1. Download the scripts from the GitHub repository.
2. Open your Roblox Studio project.
3. Navigate to the `StarterPlayerScripts` or `StarterCharacterScripts` folder.
4. Drag and drop the desired script into the appropriate folder.

## Use

### Fight Button Script

1. Place the `FightButtonScript.lua` script inside the `StarterPlayerScripts` or `StarterCharacterScripts` folder in Roblox Studio.
2. Run your Roblox game.
3. Use the left mouse button to punch or charge up.
4. Hold the left mouse button to charge up to 100.
5. Release the left mouse button to perform a grab attack if fully charged.

### Part Movement Script

1. Create a part in your Roblox game.
2. Place the `PartMovementScript.lua` script inside the part.
3. Run your Roblox game.
4. When a player touches the part, it will move up by 5 studs.
